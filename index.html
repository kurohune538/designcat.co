事業内容

企画の段階から、デザイン、開発、リリース後の改善まで。プロジェクトの状況に合わせて、必要なところを担います。

  • 01

    Webサービス開発

    要件の整理から設計、実装、インフラ構築、運用まで一貫して担当します。立ち上げ期のプロダクトも、既存サービスの改修も対応します。

    • Next.js
    • TypeScript
    • AWS
  • 02

    モバイルアプリ開発

    iOS / Android アプリを開発します。ストアへの公開から、ユーザーの反応を見ながらの継続的なアップデートまでサポートします。

    • React Native
    • Expo
    • iOS / Android
  • 03

    UI/UXデザイン

    使う人の目線で体験を設計し、画面デザインやデザインシステムに落とし込みます。実装までを見据えた、開発とつながるデザインを行います。

    • UI設計
    • プロトタイピング
    • Figma
  • 04

    技術コンサルティング・開発支援

    技術選定やアーキテクチャ設計、既存システムの改善、開発チームへの参画など、事業の状況に合わせて伴走します。

    • 技術選定
    • 設計レビュー
    • チーム参画
